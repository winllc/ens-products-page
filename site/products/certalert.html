CertAlert · Certificate expiration visibility

Every certificate in your directory, and who answers for it.

CertAlert ingests all of the user and server object records from your directory and puts their certificate expirations in one place. Each record carries the points of contact responsible for it, and a dashboard and metrics show where the organization stands — so an expiring certificate is a planned renewal, not a surprise.

What it does

Directory ingest

All user and server objects

CertAlert brings in every user and server object record from the directory, so the view is complete from the start — not limited to the certificates someone remembered to add to a spreadsheet.

Expirations

Better visibility into what’s expiring

Certificate expirations across people and servers are visible in one place, so the ones coming due can be seen and worked well before they lapse.

Points of contact

A named owner for every record

Manage the points of contact responsible for each record, so when a certificate needs attention it is clear who to go to — especially for servers, where the directory alone rarely says.

Dashboard & metrics

Where the organization stands

A dashboard and metrics summarize certificate health across the directory, for the people who need the overall picture rather than a single record.

How it fits

  1. The directory stays the source of truth. User and server objects are ingested from the directory you already run, rather than entered by hand into a separate inventory.
  2. Expirations come into view. Certificates across every ingested record are shown together, so what is coming due is visible at a glance.
  3. Owners are attached. Points of contact are managed alongside each record, closing the gap between knowing a certificate is expiring and knowing who will renew it.
  4. Leadership sees the trend. The dashboard and metrics roll it all up into an organization-wide view.

Why it helps

Fewer surprise expirations

An expired server certificate can take a service down, and an expired user certificate can lock someone out. Seeing them coming turns both into routine work.

No more hunting for an owner

With points of contact kept on each record, the time between “this is expiring” and “someone is renewing it” gets shorter.

Complete by construction

Because the inventory is built from the directory itself, coverage does not depend on anyone keeping a list up to date.
