How we build

The directory stays the source of truth

People, groups and org structure come from LDAP. Our databases store only what the directory cannot — records, roles, permissions and history.

Certificate-first authentication

Mutual TLS with X.509 client certificates where the environment supports it, with directory username and password as the fallback.

Deploys where you already are

Containerized, self-hosted, and configured through environment variables and external config rather than edits to a shipped file.
